# MI Research

카카오페이 전사 전략 조직의 Market Intelligence 리서치 하네스입니다. 내년도 사업계획
수립을 위해 아래 11개 사업영역의 시장/규제/경쟁/해외 동향을 조사하고, 전사 부서에 공유할
트렌드·인사이트 리포트를 만듭니다.

결제 · 대출 · 보험 · 투자&증권 · 카드중개 · 통신중개 · 광고 · 데이터 기반 비즈니스 ·
머니&송금 · 그로스 · 기술

## 결과물 보는 법

- **완성된 리포트**: [reports/](reports/) 폴더. 본문의 모든 숫자에는 각주로 원본 출처
  링크가 달려 있습니다 — 각주를 클릭해 원문을 직접 확인할 수 있습니다.
- **검증 상태**: [review/](review/) 폴더의 체크리스트에서 리포트의 각 숫자가 어떻게
  검증됐는지 확인할 수 있습니다.
- **전체 진행 현황**: [research-tracker.md](research-tracker.md)에서 도메인 × 분석축별
  진행 상태(미착수/조사중/초안완료/검수완료)를 한눈에 볼 수 있습니다.
- **원 근거 자료**: [evidence/](evidence/) 폴더에 도메인별로 조사한 모든 사실/수치와
  출처가 원장 형태로 쌓여 있습니다.

## 이 레포의 작동 방식

이 프로젝트는 코드가 아니라 자연어(마크다운)로 정의된 4개의 Claude Code 서브에이전트가
협업하는 구조입니다. 자세한 규칙은 [CLAUDE.md](CLAUDE.md)를 참고하세요.

1. **market-researcher** — 웹에서 실제로 조사하고, 찾은 내용을 출처와 함께 기록
2. **data-manager** — 크롤링/계산이 필요한 정량 지표를 처리 (필요한 경우만)
3. **report-writer** — 기록된 근거만 가지고 리포트를 작성 (임의로 숫자를 만들지 않음)
4. **fact-checker** — 리포트의 모든 숫자를 원본 근거와 대조 검증

리서치(근거 수집) → 작성 → 검수를 서로 다른 에이전트가 맡도록 분리한 것은, 전사 대상
리포트에 잘못된 숫자(할루시네이션)가 들어가는 것을 구조적으로 막기 위함입니다.

## 다른 PC에서 이어서 작업하기

이 레포는 별도 설치 없이 동작합니다.

```bash
git clone <이 레포 URL>
cd mi-research
claude
```

`.claude/` 폴더에 서브에이전트 설정이 포함되어 있어, clone하는 즉시 동일한 방식으로
리서치를 이어갈 수 있습니다.
